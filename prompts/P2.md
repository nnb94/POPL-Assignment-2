# Prompts for P2 (word for word)

## Prompt 1 — split/3

Write split/3: every split of the list into two non-empty parts, in order.

## Prompt 2 — expr/2

Write expr/2: every expression tree over a list of numbers.

## Prompt 3 — eval/2

Write eval/2 with the exact-division rule.

## Prompt 4 — to_string/2

Write to_string/2 using the canonical parenthesis rule.
